## 二、三條互不相干的線

```
線 A  辨識能力          名牌（在手上） → 起手手牌（階段 0 量測 → …）
線 B  帳號與同步        uid 欄位（與 Google 無關） → Google 登入 → R2 同步
線 C  工程債與信任      未結案的「引擎沒啟動」回報、CI 的 replay check、
                        packaged app smoke test
```

**它們之間沒有依賴。** 之前看起來綁在一起，是因為兩個誤會：

1. 「指紋要放 R2，所以要先做 Google 登入。」——不是。指紋只需要一個放 1.8 MB 靜態檔案的
   地方，而 manifest indirection（見 `opening-hand-plan.md`）讓託管位置隨時可改、不必發版。
   **線 B 不是線 A 的前置。**
2. 「起手手牌要靠卡名 OCR，而名牌那份實測說 CJK OCR 不可靠，所以起手手牌卡住了。」——不是。
   那是資訊，不是阻塞，而且卡名是**封閉候選集**（牌組 30 張），與開放集的玩家名字條件不同。
   要不要保留那一層，是階段 0 量測完才需要回答的問題。

線 A 內部唯一的順序是「名牌先收尾」。線 B 內部的順序是「uid 可以單獨先做」。線 C 全部可以
插隊，因為它們都很小。

## 三、需要你決定的事

只有五個，按「該先回答」排序。每個都附上不決定的代價。

### D1. 名牌那份未 commit 的工作要不要現在收尾？

- 選項：(a) 收尾並發版 (b) 收尾但先不發版，累到下一版 (c) 擱置
- **建議：(a) 或 (b)，不要 (c)。**
- 理由：它是唯一擋住線 A 的東西，而且未 commit 的變更愈久愈難重新進入狀況。
- 不決定的代價：起手手牌無法開工，`calibration.rs` 上再疊第二個未完成的功能會很難拆。

### D2. Google 登入要不要做？

- 選項：(a) 現在做 (b) 只做階段 0 的 uid 欄位，Google 那半延後 (c) 整條延後
- **建議：(b)。**
- 理由：uid 欄位 + 回填 + 引擎填 uid 沒有使用者可見變化、不需要任何 Google 設定與伺服器，而且
  **回填在資料量小的時候最便宜**。做完它，「要不要做登入」在未來任何時間點都會變便宜，而你
  什麼都還沒承諾。反過來，Google 那半的成本大半不是程式：隱私權政策與服務條款頁面是階段 0
  的硬前提，帳號刪除與匯出是義務，而且上線後不可逆。
- 還缺的資訊：**有多少使用者真的有第二台 PC。** 這是這個功能唯一的價值來源，而 telemetry 用
  匿名 install id、且明文規定不得與同步識別碼共用，所以它剛好無法回答這個問題。要嘛去問社群，
  要嘛承認是在賭。
- 不決定的代價：低。這是唯一可以無限期擱置而不累積成本的一條——只要 uid 先做掉。

### D3. 指紋託管要不要採用 manifest indirection？

- 選項：(a) 採用（編譯進 app 的只有 manifest URL，資料位址寫在 manifest 裡）
  (b) 不採用，直接把資料 URL 編譯進 app
- **建議：(a)。**
- 理由：`telemetry/config.ts` 已經記著這個教訓——端點被編譯進每個 build，改端點等於發版，而且
  舊網址得永遠回應。一層 indirection 就讓 GitHub → R2 的搬遷不必發版。
- 這個決定**取代**了「GitHub 還是 R2」：採用之後，v1 放哪裡都不再是永久決定。
- 不決定的代價：把託管位置焊進版本裡，將來搬家要維護兩份或放棄舊版本。

### D4. 起手手牌要不要開始階段 0（量測）？

- 選項：(a) 名牌收尾後立刻做 (b) 排到更後面 (c) 不做
- **建議：(a)。** 但要清楚它是什麼：**錄一段換牌過程並逐格看**，不是寫程式。成本是一個下午。
- 它會回答四個問題，其中兩個可能讓後面整個階段消失：
  - 換後那四張還在不在同一個面板上（決定整個計畫的規模）
  - 替代插畫與閃卡有多常見（可能讓插畫比對整層不必做）
- 不決定的代價：所有關於指紋、OCR、卡圖託管的討論都會繼續在空中打轉，因為它們全部依賴這四個
  答案。**這是目前最划算的一步。**

### D5. 卡名 OCR 要不要留在辨識架構裡？

- **建議：現在不要決定。** 等 D4 的量測結果，以及「真實 40 張牌組裡 `(cost, atk, life, type)`
  的碰撞率」這個數字。
- 記在這裡只是為了讓你知道它已經被記下來了，不必掛在心上。
