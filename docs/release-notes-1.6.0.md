# SVWB Analyzer 1.6.0

## 對遊戲的負擔更小
- 辨識對局時佔用的 CPU 明顯降低，和遊戲一起開著也更順暢。

## 環境數據
- 只統計目前卡包上線之後的對戰，不再混入上一個環境的數字。
- 資料會在背景先準備好，點進頁面就能直接看到。
- 切換統計期間時，舊的數字會先變淡，等新資料到了才換上，不會看錯期間。
- 還沒選過職業的話，會先顯示你最近一場使用的職業。

## 分析器與對局列表
- 調整篩選條件後，結果會立刻更新。
- 對戰表的勝率色塊加大，一眼就能比較；欄位標題也可以用鍵盤排序。
- 場數太少的對位會變淡顯示，滑鼠移上去會說明原因，避免把 3 場 100% 當成可靠的數字。
- 對局列表的捲軸可以直接拖曳或點擊翻頁，也能用方向鍵、PageUp／PageDown 捲動；捲動時卡片不會再一直亮起。

## 牌組
- 關閉牌組編輯時，如果還有沒儲存的變更，會先確認是否要捨棄。
- 儲存牌組後，會告訴你是更新了原本的版本，還是另存成新版本。

## 設定與其他
- 「資料管理」重新設計：清除資料時可以選擇要清除哪些項目，清除前會自動備份，需要時也能從備份清單還原。
- 「贊助」頁改為「關於」頁，介紹工具本身，贊助方式也放在這裡。
- 載入中、讀取失敗、還沒有任何對局時，各頁都會清楚說明目前的狀況。
- 整體配色、動畫與用語重新整理，畫面更一致，文字也更好懂。

更新後重新啟動即可，不需要調整任何設定。

起手的統計分析頁面仍在累積資料，這一版還不會開放。
