# SVWB Analyzer 1.6.0

## 更省資源
- 辨識吃的 CPU 大幅下降：比對改用整數運算、最多只用兩個執行緒，職業與徽章只在對戰開始的畫面才辨識。邊打邊開著 SVWB Analyzer，遊戲會比以前順。

## 環境數據
- 只計算目前卡包上線之後的對戰，舊環境的數字不再混進來。
- 進到這一頁之前資料就已經先抓好，打開時不用等；資料超過 15 分鐘才會重新抓取。
- 切換統計區間時，舊的數字會先淡下去，不會被誤認成新選的區間。
- 還沒選過職業時，預設顯示你最近一場用的職業。

## 介面
- 整體配色與動畫統一，看起來更安靜；提示框改成短暫淡入，滑過圖表時不會一直彈出來。
- 對局列表的捲軸可以拖曳，也可以用鍵盤捲動，捲動時卡片不會一直閃。
- 對戰表的欄寬重新分配，勝率色塊更大、更好比較，欄位標題可以用鍵盤排序。
- 樣本太少的對位會特別標出來，3 場 100% 不會再和 100 場看起來一樣可靠。
- 讀取失敗、資料還在載入、還沒有任何對局時，各頁都會清楚說明現在的狀況。
- 組牌器關閉前，如果有沒存的變更會先確認；儲存牌組後會告訴你是更新了原本的版本，還是另存成新版本。
- 「贊助」頁改成「關於」頁。
- 介面文字全面改寫成較口語、一致的說法。

## 資料管理
- 設定裡的「資料管理」重新設計：清除資料前可以選要清除哪些項目，並會先自動備份；備份清單也移到這裡，可以從中還原。
