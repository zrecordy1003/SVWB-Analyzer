# SVWB Analyzer 1.3.1

一個小版本，只做一件事：**當辨識完全沒有反應時，讓你手上有東西可以回報。**

1.3.0 之後有使用者回報「進入對戰完全沒有被記錄」，而程式當時完全查不出原因——側邊欄
顯示綠燈、診斷包匯出卻是空的。這一版修掉的就是「查不出原因」本身。

沒有資料庫變更，升級不需要任何動作。

---

## 改進

- **辨識引擎的啟動記錄會留在本機。** 程式現在會把引擎的啟動環境（版本、系統、架構、
  安裝路徑）以及它結束的原因寫進 `engine.log`。以前這些訊息只出現在開發用的主控台，
  正式版沒有主控台也沒有檔案，所以引擎啟動失敗時**沒有任何地方看得出來**。
- **這份記錄不受「記錄辨識異常」開關影響。** 那個開關管的是要不要存下你的遊戲畫面；
  啟動記錄只有幾行文字、不含畫面，關掉畫面不該連唯一能解釋問題的東西一起關掉。
- **辨識引擎沒有啟動時會明確警告。** 側邊欄原本的綠燈只代表「找到遊戲視窗」——那是
  兩件不同的事，而視窗偵測跟引擎完全無關，所以引擎死掉時燈還是綠的。現在這種情況會
  顯示紅色警告，並告訴你這場不會被記錄。

---

## 修正

- **「匯出診斷包」在最需要它的時候不能按。** 匯出原本要求至少記錄到一筆辨識異常，
  而「引擎從未啟動」正好是一筆異常都不會有的狀態——辨識沒有跑起來，自然也沒有對
  任何事情產生疑慮。於是唯一能解釋問題的使用者，得到的是「沒有可匯出的紀錄」。
  現在只要有啟動記錄就能匯出。
- **匯出的報告會告訴收件者先看哪裡。** 一份沒有異常事件的診斷包不代表一切正常，
  報告裡現在會直接說明這件事，而不是看起來像一份乾淨的體檢表。

---

## 如果你的辨識沒有反應

請到**設定 → 辨識診斷 → 匯出診斷包**，把產生的 zip 回報。裡面的 `engine.log` 通常
可以直接指出原因，不需要你提供錄影或截圖。

順帶一提，有兩件事值得先自己確認：

- **遊戲和本程式，有沒有其中一個是用「以系統管理員身分執行」開的？** 兩者權限不同時，
  Windows 不允許本程式擷取遊戲畫面。請讓兩者一致。
- **你玩的是電腦版客戶端嗎？** 手機版透過模擬器執行時畫面排版不同，目前不支援。
